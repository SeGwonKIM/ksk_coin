# F7.2 — 탭 네비게이션

**먼저 `ksk-contract` 스킬을 읽는다.**

## ⚠ 단독으로 돌린다

이 스킬은 **전역 레이아웃을 바꾼다.** 다른 `ksk-*` 스킬과 동시에 돌리면 같은 줄에서 충돌한다.

시작 전에 확인한다.

```bash
git -C . status --short     # 깨끗해야 한다
```

다른 작업이 진행 중이면 멈추고, 그 작업이 커밋된 뒤에 시작한다고 보고한다.

## 이 층이 하는 일

패널이 여섯 개를 넘으면 모바일에서 스크롤이 길어져 쓸 수 없다. 탭으로 나눈다.

## 설계

- 패널을 감싸는 컨테이너에 `data-tab="mine|market|estate|home|job|asset"` 을 붙인다.
- 탭 버튼 줄을 헤더 바로 아래에 둔다. 모바일에서는 가로 스크롤되는 한 줄.
- 전환은 `el.hidden` 으로 한다. `style.display` 를 직접 만지지 않는다.
- 선택한 탭은 `localStorage` 에 남겨 다음 방문에 복원한다. **읽기·쓰기를 `try/catch` 로 감싼다**
  (`data:` URL 등 저장이 막힌 환경에서 예외가 난다).
- HUD(상단 지표 7칸)는 **탭과 무관하게 항상 보인다.** 세계의 상태는 어느 탭에서든 필요하다.
- **존재하지 않는 탭은 버튼을 만들지 않는다.** F2 가 아직 없으면 `부동산` 탭도 없다.
  `document.querySelectorAll('[data-tab]')` 로 실제 있는 것만 훑어 버튼을 만든다.

## 중요 — 렌더 훅과의 관계

숨겨진 탭의 패널도 `renderHooks` 는 계속 돌린다. 그래야 탭을 켤 때 값이 최신이다.
성능이 문제되면 그때 최적화한다. **지금 최적화하려고 훅 구조를 바꾸지 않는다.**

## F7.3 순자산 대시보드

`자산` 탭에 한 화면 요약을 만든다.

```
순자산 = 현금 + 보유 KSK 평가액 + 스테이크 평가액 + 부동산 평가액 + 살림 잔존가치
```

없는 항목은 0 으로 두고, 있는 것만 합산한다. `grep` 으로 각 상태 필드의 존재를 확인하고
`typeof` 로 방어한다. 다른 스킬이 아직 안 붙은 상태에서도 깨지지 않아야 한다.

## 끝내기 전

1. `ksk-verify` 절차 통과
2. 모든 탭을 눌러 각 패널이 보이고, 새로고침 후 선택이 복원되는지 확인
3. 모바일 375px 폭에서 탭 줄이 넘치지 않고 가로 스크롤이 생기지 않는지 확인
4. 채굴을 켠 상태에서 탭을 옮겨도 채굴이 멈추지 않는지 확인
5. `PRD.md` §6 의 F7.2·F7.3 항목 갱신
