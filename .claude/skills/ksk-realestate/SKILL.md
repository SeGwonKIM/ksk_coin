# F2 — 부동산: 매물과 매매

**먼저 `ksk-contract` 스킬을 읽는다.** 상태 스키마·구역 규약·금지 사항이 거기 있다.
작업 구역은 `grep -n "\[F2:" index.html` 로 찾는 세 곳뿐이다.

## 이 층이 하는 일

건물은 **자산이면서 동시에 채굴 인프라**다. 이 스킬은 자산 쪽(사고 파는 것)만 만든다.
채굴장으로 쓰는 부분은 `ksk-mining-infra`(F3)가 이 데이터를 받아 이어 붙인다.

## 상태

`freshState()` 의 F2 구역에 한 줄로 추가한다.

```js
re: { owned: [], mkt: 1.0 },   // F2 — owned: [{id, price(매입가), at(블록)}], mkt: 시세 배수
```

## 건물 데이터

`RIGS` 옆에 `ESTATES` 상수를 F2 JS 구역에 만든다. **실제 랜드마크 이름 + 게임 균형용 근사 가격.**

각 항목에 필요한 필드:

| 필드 | 뜻 | F3 이 쓰는가 |
|---|---|---|
| `id` | 영문 슬러그 | |
| `name` | 표기 이름 (예: `타워팰리스`) | |
| `area` | 지역 (예: `서울 강남`) | |
| `use` | 용도 — `주거` / `오피스` / `상가` / `토지` | |
| `py` | 평형 | |
| `real` | **실제 참고 시세 (억원)** — 나머지가 여기서 파생된다 | |
| `yrPct` | **연 임대수익률** — 실제 시장값을 그대로 쓴다 (원룸 6.0% ~ 타워팰리스 1.8%) | |
| `feePy` | 평당 월 관리비 (만원) — 관리비는 임대료가 아니라 **면적**에 비례한다 | |
| `price` | 파생: `real × 100` (1억원 = 100 KSK) | |
| `rent` | 파생: `price × yrPct ÷ 12` — F2 가 적립하고 F5 가 월말 정산으로 넘겨받는다 | |
| `fee` | 파생: `feePy × py × 0.01` | ✅ |
| `kw` | 수용 전력 한도 (kW) | ✅ |
| `cool` | 냉각 계수 (1.0 = 기준, 낮을수록 전기 덜 듦) | ✅ |

**8~12개면 충분하다.** 원룸·오피스텔 같은 저가 매물부터 랜드마크급까지 가격 폭을 벌려,
초반에 살 수 있는 것과 목표가 되는 것이 함께 있어야 한다.
가격은 `S.price` 로 환산했을 때 채굴 수익으로 **수십 분~수 시간** 안에 첫 매물을 살 수 있게 잡는다.

## 만들 기능

| | 내용 |
|---|---|
| F2.1 | `ESTATES` 데이터 테이블 |
| F2.2 | 매물 목록 패널 + 지역·용도·가격 필터 (`select` 또는 버튼 토글) |
| F2.3 | 매입 — 현금 결제, 취득세·중개수수료 차감, 잔액 부족 시 버튼 비활성 |
| F2.4 | 보유 목록 — 매입가 대비 현재 시세, 평가손익 |
| F2.5 | 시세 변동 — `tickHooks` 에서 `S.re.mkt` 를 평균회귀 랜덤워크로 움직인다 |
| F2.6 | 매도 — 차익 실현, 중개수수료 차감 |
| F2.7 | 취득세 4.6% · 중개수수료 0.5% (게임 균형용 근사) |
| F2.x | 임대료 − 관리비 를 초당 적립 (`estNetRentPerSec()`) |

**임대료를 F2 가 적립하는 이유.** 원래 F5(월 정산)의 몫으로 뒀는데, 그러면 F2 만 만든 상태에서
건물을 사도 수입이 없어 "각 기능은 그것만으로 동작해야 한다"는 계약을 어긴다.
그래서 `ksk-jobs` 가 월급에 쓴 것과 같은 방식으로 F2 가 초당 적립하고, F5 가 붙으면
월말 일괄 정산으로 넘겨받는다. 코드의 해당 `tickHooks` 줄에 그 표시를 남겨 뒀다 —
`ksk-monthly` 스킬이 그 주석을 찾아 이중 청구를 피한다.

## 규칙

- **수수료를 빠뜨리지 않는다.** 코인·현금이 오가면 `FEE_RATE`(0.01%)를, 부동산 거래면 위 취득세·중개수수료를 적용한다.
- 같은 건물을 여러 채 살 수 있게 할지 정한다. **하나만 소유**로 시작하는 게 단순하다 (매물에서 사라지고 보유로 이동).
- 시세는 `S.re.mkt` 배수 하나로 전체를 움직인다. 건물별 개별 시세는 v2로 미룬다.
- 매입 직후 매도해 차익을 얻는 무한 루프가 생기지 않게, 매도가에 **중개수수료 + 스프레드**를 물린다.
- 화면 어딘가에 "가격은 게임 균형용 근사치이며 실제 시장 정보가 아닙니다"를 남긴다. 백서 §9 요구사항이다.

## 끝내기 전

1. `ksk-verify` 절차 통과
2. 매입 → 보유 목록 반영 → 매도 → 현금 회수가 실제로 동작
3. 현금이 부족할 때 매입 버튼이 비활성
4. `PRD.md` §6 의 F2.1~F2.7 을 `✅` 로 갱신
5. 커밋: `feat: F2 부동산 매물·매매 추가 — …`
