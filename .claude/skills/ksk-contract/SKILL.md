# ksk_coin 공통 계약 — 병렬 작업의 규칙

`C:\AI-Agent\ksk_coin` 은 **단일 `index.html`** 하나로 동작한다. 여러 에이전트가 동시에
같은 파일을 고치면 충돌하므로, 파일 안을 **기능별 예약 구역**으로 나눠 뒀다.

**작업 전에 이 문서를 끝까지 읽는다. 구역 밖을 고치면 다른 사람의 작업을 깨뜨린다.**

## 1. 문서 위치

| 파일 | 내용 |
|---|---|
| `WHITEPAPER.md` | 설계 근거, 수식, 검산, 참고문헌. 경제 규칙을 바꾸려면 먼저 읽는다 |
| `PRD.md` §6 | 기능 분해 목록(F0~F8)과 상태(`✅`/`🔨`/`⬜`) |
| `index.html` | 전부. CSS·HTML·JS 인라인 |

## 2. 예약 구역 — 내 구역 안에서만 쓴다

`index.html` 에 구역이 세 곳씩 있다. `F2`(부동산) `F3`(채굴인프라) `F4`(살림살이)
`F5`(월정산) `F8`(직업).

```
/* ==== [F2:부동산] CSS 시작 ==== */   ...   /* ==== [F2:부동산] CSS 끝 ==== */
<!-- ==== [F2:부동산] 패널 시작 ==== -->  ...  <!-- ==== [F2:부동산] 패널 끝 ==== -->
/* ==== [F2:부동산] JS 시작 ==== */    ...   /* ==== [F2:부동산] JS 끝 ==== */
```

`grep -n "\[F2:" index.html` 로 자기 구역 세 곳을 먼저 찾는다.
**시작/끝 마커 줄 자체는 절대 지우거나 옮기지 않는다.** git 이 구역별로 병합할 수 있는 근거다.

## 3. 확장 훅 — 메인 루프를 고치지 않는다

메인 루프와 `render()` 를 직접 건드리면 모두가 같은 줄에서 충돌한다. 대신 훅에 등록한다.

```js
/* ==== [F2:부동산] JS 시작 ==== */
tickHooks.push(function(dt){    // 매 500ms, dt 는 초 (상한 2초)
  // 시세 변동, 임대료 적립 같은 시간 진행
});
renderHooks.push(function(){    // 매 500ms
  // 자기 패널의 DOM 갱신만
});
/* ==== [F2:부동산] JS 끝 ==== */
```

훅 안에서 던진 오류는 `runHooks` 가 삼켜서 세계가 멈추지 않는다. 그래도 오류를 남기지 않는다.

## 4. 상태 스키마

상태는 전역 `S` 하나다. `freshState()` 가 초기값을 만들고 `localStorage` 에 통째로 저장된다.

### 건드리지 말 것 (F0·F1 소유)

```js
coin, cash, issued, mined, blocks, blockTimer, price, prevPrice, hist, slip,
demand, netHash, baseHash, counts, mode, staked, attests, attestTimer,
slashed, fees, poolPaid, solo, peakPrice, spent, log, over
```

- `S.issued` = **세계 전체 발행량**, `S.mined` = **내가 받은 양**. 절대 섞지 않는다.
  이 둘을 한 변수로 겸했다가 지분이 4%→80% 로 폭주한 적이 있다 (`WHITEPAPER.md` §4.2).
- 불변식: `S.mined <= S.issued`. 코인을 지급하는 코드를 쓰면 이 식을 깨는지 확인한다.

### 새 필드 추가 방법

`freshState()` 의 **자기 구역 주석 바로 뒤**에 한 줄로 추가하고, 접두어로 소유를 표시한다.

```js
re: { owned: [], listings: null },   // F2 부동산
```

`load()` 가 `Object.assign(freshState(), 저장값)` 을 쓰므로, 없던 필드는 자동으로 초기값이 된다.
**옛 저장값과 새 규칙이 섞이면 안 되는 변경**(발행 규칙·단위 변경)에서만 `SAVE_KEY` 를 올린다.
지금은 `ksk_coin_v4` 다. 기능 추가만이면 올리지 않는다.

## 5. 쓸 수 있는 공용 함수

```js
$(id)                 // getElementById
log(msg)              // 원장에 한 줄 (HTML 허용, 최근 30줄만 유지)
save()                // localStorage 저장 (실패해도 안전)
won(v)                // 12,345    원 단위 (정수 반올림 + 천단위)
ksk(v)                // 1.23억 / 4.5만 / 12.3 / 0.123
kskFull(v)            // 123,456,789
pw(v)                 // 시세 표기 (100 미만이면 소수 5자리)
clamp(v, a, b)
gameYears()           // 세계 경과 연수 (블록 × 17.52 ÷ 8760)
era()                 // 반감기 회차 0..24
S.price               // 현재 KSK 시세 (원/KSK)
myShare()             // 현재 내 채굴/검증 지분 (0~1)
FEE_RATE              // 0.0001 — 전송·거래 수수료 0.01%
```

**돈이 오가는 기능은 반드시 `FEE_RATE` 를 적용한다.** 백서 §4.4 에 0.01% 로 못박혀 있다.

시간 축척은 **1 실제초 = 1 게임시간**이다. 한 달은 730 게임시간(= 730초)이다.
월 단위 비용은 `월액 / 730 * dt` 로 초당 환산한다.

## 6. 화면 톤

기존 게임 3개와 같은 톤을 유지한다. 새 색을 만들지 말고 CSS 변수를 쓴다.

```
--bg #0d1117  --panel #161b22  --line #26303d  --txt #e6edf3
--dim #8b949e  --up #3fb950  --down #f85149  --gold #e3b341
```

- 패널은 `<div class="panel"><h2>제목</h2>…</div>`
- 수치 행은 `<div class="row"><span>라벨</span><b id="…">값</b></div>`
- 버튼은 `button` / `button.ghost` / `button.buy` / `button.sell`, 작은 건 `.sm`
- 클릭은 개별 `onclick` 대신 **data 속성 + 기존 document 위임 리스너**를 쓴다
  (예: `data-buyre="tp1"`). 위임 리스너에 분기 한 줄만 추가하는 것은 허용된 공유 접점이다.
- 모바일 480px 이하에서 버튼 최소 높이 46px 은 이미 전역으로 걸려 있다.

## 7. 금지

- 외부 라이브러리·CDN·`<link>`·빌드 도구. **네트워크 요청 0건**을 유지한다.
- 실제 시세·환율 연동 (백서 §9 에서 명시적으로 제외했다).
- 현금 입출금, 실명 자산 거래, 투자 조언, 수익 보장 문구.
- 실제 건물·상품 가격을 사실처럼 표기하기. **게임 균형용 근사치**임을 화면에 남긴다.
- `S.issued` / `S.mined` 혼용, 불변식 위반.
- 루트 `C:\AI-Agent` 에서 `git add`. `ksk_coin` 은 독립 저장소다.
- 확인 없이 `git push`.

## 8. 끝내기 전 검증 (필수)

`ksk-verify` 스킬의 절차를 따른다. 최소한 이 세 가지는 통과해야 한다.

```bash
node -e "const s=require('fs').readFileSync('index.html','utf8');const m=s.match(/<script>([\s\S]*)<\/script>/);new Function(m[1]);console.log('JS 문법 통과')"
```

1. 위 문법 검사 통과
2. 브라우저에서 열어 콘솔 오류 0건, 자기 패널이 실제로 동작
3. 불변식 `S.mined <= S.issued` 유지, 채굴 지분이 설계값(1단계 4%)에서 벗어나지 않음

## 9. 커밋

한국어로, 무엇을 왜 바꿨는지 제목에 넣는다. 작업 후 `PRD.md` §6 의 해당 항목을 `⬜ → ✅` 로 바꾼다.

```
feat: F2 부동산 매물·매매 추가 — 건물이 자산이면서 채굴장이 되는 첫 조각
```

`update`, `fix bug` 같은 빈 제목은 쓰지 않는다.

## 10. 병렬 실행 계획

**같은 구역을 두 에이전트가 동시에 맡기지 않는다.** 그리고 순서 제약이 있다.

| 순서 | 스킬 | 구역 | 동시 실행 |
|---|---|---|---|
| 0 | `ksk-tabs` (F7.2) | 전역 레이아웃 | **단독** — 패널 배치를 바꾸므로 혼자 돌린다 |
| 1 | `ksk-realestate` (F2) | `[F2:…]` | ✅ 아래 셋과 동시 가능 |
| 1 | `ksk-household` (F4) | `[F4:…]` | ✅ |
| 1 | `ksk-jobs` (F8) | `[F8:…]` | ✅ |
| 2 | `ksk-mining-infra` (F3) | `[F3:…]` | F2 완료 후 (건물 데이터가 필요하다) |
| 2 | `ksk-monthly` (F5) | `[F5:…]` | F2·F4·F8 완료 후 (정산할 항목이 필요하다) |
| 상시 | `ksk-verify` | 없음 | 각 작업 끝에 |

**1단계 셋(F2·F4·F8)은 서로 의존이 없어 진짜로 동시에 돌릴 수 있다.**
F4 는 건물이 없어도 "보관함"에 사 두는 것으로 먼저 만들고, F2 가 끝난 뒤 배치를 연결한다.
