# ksk_coin — KSK 코인: 휴대폰으로 캐는 가상 생활경제

휴대폰으로 가상화폐 `KSK`를 캐고, 그 코인으로 실제 건물을 사고 살림을 채우고 직업을 갖는
가상 생활경제 시뮬레이터입니다. 빌드 도구 없이 `index.html` 하나로 동작하며,
**외부 네트워크 요청이 0건**이라 인터넷 없이도 돌아갑니다.

> ⚠ **시뮬레이션입니다.** 실제 블록체인에 발행하지 않고 실제 화폐가 드나들지 않습니다.
> `KSK`는 현실 가치가 없는 숫자이며, 투자 조언이 아닙니다.
> 등장하는 건물 이름은 보드게임이 실제 지명을 쓰는 것과 같은 표기이고,
> 가격은 **실제 참고 시세**를 밝혀 함께 보여 주지만 **실시간 시세 연동은 하지 않습니다.**
> 가상 인물·초대한 사람은 시뮬레이션된 값이고 실제 사용자가 아닙니다.

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. PC와 휴대폰 모두에서 동작합니다.

배포본: **https://segwonkim.github.io/ksk_coin/**

## 화폐 — KSK 하나뿐

**원화가 없습니다.** 거래소도 없습니다. 집·가전·생활비·월급이 전부 코인으로 오갑니다.

| | |
|---|---|
| 단위 참조 | **1 KSK = 100만원** (이해용 표시 — 거래는 KSK 로만) |
| 최소 단위 | **0.000001 KSK = 1원** |
| 물가 배수 | 코인이 귀해지면 내려가 같은 물건을 더 적은 코인으로 삽니다 |
| 수수료·세금 | 아무에게도 가지 않고 **영구 소각**됩니다 |

## 합의 — 보안 최대, 기기 자원 최소

| 단계 | 방식 | 기기 부하 |
|---|---|---|
| 1단계 초기 분배 | 가벼운 작업증명 (3프레임당 1회) | CPU 약 **6%** (모바일 4%) |
| 2단계 더 머지 | 지분증명 — 32,000 KSK 예치 시 전환 | **12초에 해시 1회** |

보안의 담보가 전기가 아니라 몰수 가능한 예치금(슬래싱)이라 자원을 거의 쓰지 않습니다.

## 발행 설계

| 항목 | 값 |
|---|---|
| 총 발행 상한 | **55억 KSK** |
| ├ 채굴로 발행 | 50억 KSK |
| └ 사전 채굴 (재단 잠금) | 5억 KSK · 총량의 9.09% |
| 총 발행 기간 | 50년 (반감기 25회 · 2년마다) |
| 초기 블록 보상 | 250만 KSK |
| 목표 블록 시간 | 17.52초 |
| 시간 축척 | 1 실제초 = 1 게임시간 (한 달 ≈ 12분) |
| 채굴 시작 기본 지급 | 50 KSK |

`250만 × 1,000블록 × 2 = 50억` (등비수열 합). 25에라 누적 4,999,999,850.99 KSK에
마지막 잔여 149.01을 더해 정확히 50억에서 채굴이 끝납니다.

**사전 채굴 5억은 그 50억에서 떼지 않고 위에 얹었습니다.** 등비수열이 정확히 50억을
만들도록 맞춰져 있어서, 안에서 떼면 블록 보상·반감기 일정·검산이 모두 어긋납니다.
재단 물량은 **잠겨 있습니다** — 유통되지도, 예치되지도, 희소성 계산에 들어가지도 않습니다.
그래서 이 변경은 기존 균형을 건드리지 않습니다. 자세한 근거는
[WHITEPAPER.md §3.1](WHITEPAPER.md) 에 있습니다.

## 경제 층

```
채굴/검증 → KSK → 건물 매입 → 그 건물이 곧 채굴장(회선 한도·운영 효율)
                      ↓                    ↓
                 임대수익          살림살이(전기·인테리어 등급·평면 배치)
                      ↓                    ↓
     생활비·보유세·통신비·대출이자  ←  월급/중개수입(직업·자격·승진)
                      ↓
              월말 정산 → 못 버티면 강제 매각
```

- **부동산** 9종. 가격은 실제 참고 시세 × 100 (원룸 80 KSK ~ 타워팰리스 3,900 KSK)
- **가상 인물 8명**이 서로 거래해 매물이 사라지고 다시 나옵니다
- **담보 대출** LTV 30~70% · 이자 2~7% (담보물건별) · 마진콜
- **신용 대출** 10~1,000 KSK · 이자 1~9% (직업·근속·학력·자격·자산으로 신용 점수)
- **살림살이** 14종. 평형이 방 수를 정하고 자리가 부족하면 등급이 깎입니다
- **직업** 6종 + 자격·학위 4종. 승진·중개사 개업
- **추천인** 초대한 사람이 100 KSK를 모으면 10 KSK
