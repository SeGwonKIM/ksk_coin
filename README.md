# ksk_coin — KSK 코인: 채굴로 시작하는 가상 생활경제 세계

휴대폰으로 가상화폐 `KSK`를 캐고, 그 돈으로 실제 건물을 사고 살림을 채워 나가는 가상 생활경제
시뮬레이터입니다. 빌드 도구 없이 `index.html` 하나로 동작하며, 외부 네트워크 요청이 없어
인터넷 없이도 돌아갑니다.

> ⚠ **시뮬레이션입니다.** 실제 블록체인에 발행하지 않고 실제 화폐가 드나들지 않습니다.
> `KSK`와 게임 내 원화는 현실 가치가 없는 숫자이며, 투자 조언이 아닙니다.
> 등장하는 건물 이름은 보드게임이 실제 지명을 쓰는 것과 같은 표기이고, 가격은 게임 균형용 근사치입니다.

## 플레이 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. PC와 휴대폰 모두에서 동작합니다.

- **채굴 시작** — 이 기기의 속도를 2~3초 재고 그에 맞춰 난이도를 정합니다. 느린 기기에서도 수익 속도가 비슷합니다.
- **거래소** — 캔 코인을 팔아 현금을 만듭니다. 팔면 시세가 눌리고 사면 밀려 오릅니다.
- **채굴 장비** — 휴대폰입니다. 비용은 전기가 아니라 대당 통신비라, 약한 폰 여러 대보다 센 폰이 유리합니다.
- 휴대폰은 화면이 꺼지면 채굴이 멈추고 돌아오면 자동으로 재개합니다.

## 발행 설계

| 항목 | 값 |
|---|---|
| 총 발행 상한 | 50억 KSK |
| 총 발행 기간 | 50년 (반감기 25회 · 2년마다) |
| 초기 블록 보상 | 250만 KSK |
| 목표 블록 시간 | 17.52초 |
| 시간 축척 | 1 실제초 = 1 게임시간 |

`250만 × 1,000블록 × 2 = 50억` (등비수열 합). 25에라 누적 4,999,999,850.99 KSK에
마지막 잔여 149.01을 더해 정확히 50억에서 발행이 끝납니다.
